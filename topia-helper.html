📒 TOPIA Helper

One bookmark that adds the gradesheet tools to TOPIA: copy students, fill the Weekly Report, and bring online homework into the gradesheet. Set it up once on each device. It updates itself.

💻 Computer (Chrome, Edge, Whale, Safari)

  1. Show the bookmarks bar: Ctrl+Shift+B (Mac: ⌘+Shift+B).
  2. Drag this button onto the bar: 📒 TOPIA Helper
  3. On any TOPIA page, click it.

📱 iPad / iPhone (Safari)

  1. Copied
  2. Tap Share (□↑) → Add Bookmark → name it TOPIA Helper → Save.
  3. Tap the Bookmarks icon (📖) → Edit → tap TOPIA Helper.
  4. Clear the address, paste, tap Done.
  5. On TOPIA, tap the address bar, type TOPIA Helper and tap the bookmark.

🤖 Android tablet / phone (Chrome)

  1. Copied
  2. Tap ⋮ → ☆ to bookmark this page, then Edit.
  3. Name it TOPIA Helper, paste over the URL, save.
  4. On TOPIA, type TOPIA Helper in the address bar and tap the bookmark.
School computer that blocks bookmarklets? Use the Chrome extension

Download topia-helper.zip, unzip it, open chrome://extensions, turn on Developer mode, click Load unpacked and pick the folder. The bookmark is easier and updates itself, so try it first.

Nothing is saved on TOPIA until you press Save there. Your TOPIA password is never read.
