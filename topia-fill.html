Gradesheet → Topia

Moves scores from the Class Gradesheet into the TOPIA Weekly Report page. Set it up once on each computer you use for TOPIA.

1. Add the bookmark

Show the bookmarks bar (Ctrl+Shift+B, or ⌘⇧B on a Mac), then drag this button onto it:

Gradesheet → Topia

Can't drag it?
  2. Right-click the bookmarks bar, choose Add page…
  3. Name: Gradesheet → Topia. URL: paste the code. Save.

2. Each time you send scores

  1. In the gradesheet, open the class, then Print & send → ⇪ Topia. Pick the days and press Copy for TOPIA.
  2. On TOPIA, open Weekly Report and choose the same class and subject.
  3. Click the Gradesheet → Topia bookmark and paste (Ctrl+V) into the box. It shows what it will fill.
  4. Press Fill. The boxes it filled turn yellow. Check them, then press TOPIA's Register.

It only fills empty boxes unless you tick “Replace scores already in TOPIA”. It never presses Register for you. If TOPIA shows only some students per page, run it on each page.

What goes where

Scores are sent as percentages and scaled to TOPIA's Perfect Score, so 9/10 participation stays 9, and 17/20 on a word test becomes 85 on a /100 row.

  • Participation → Weekly Performance: Participation
  • Writing, Essay, Summary → Writing
  • Word Test, Vocabulary Test → Vocab Test
  • Presentation → Presentation · Debate → Debate · Monthly Test → Monthly Test

Absent days and students who joined late or left are skipped. Sessions are matched by date (e.g. 1회차 (9/9) ↔ the gradesheet day dated 9/9), or by number when the class has no dates set.
